## AI Interview screen

The AI Interview assessment frame is a Vite + React + TypeScript + Tailwind app in `app/`.

```bash
cd app
npm install
npm run dev
```

Vite serves the screen at `http://localhost:5173` by default. The page opens on Sarah Williams’s completed interview: playback, the transcript dialog, the full-screen video, skill tooltips, and the question-phase accordions.
